OPERATIONAL HANDBOOK

ยินดีต้อนรับสู่ระบบเฝ้าระวัง WiFi Evil Twin ระดับสูง PHANTOM v3.0 ระบบนี้ถูกออกแบบมาเพื่อตรวจจับการโจมตีทางไซเบอร์ในเลเยอร์สัญญาณวิทยุ (Radio Frequency) โดยเฉพาะ

⚡ HYBRID AI ENGINE

สมองกล v3.0 ที่รวมเอา Machine Learning (Isolation Forest) เข้ากับ Heuristic Analysis เพื่อวิเคราะห์ความเสี่ยงรายวินาที

📡 SIGNAL JITTER TRACKING

ตรวจวัดความเสถียรของสัญญาณ ถ้าสัญญาณสวิงผิดปกติ ระบบจะระบุว่าเป็นพฤติกรรมของอุปกรณ์บุกรุก (Attack Tools)

🛡️ TARGET WATCHLIST

คุณสามารถกด SELECT เพื่อดึงเป้าหมายที่น่าสงสัยขึ้นมาเฝ้าดูเป็นกรณีพิเศษ (Pinned Intel)

🔎 LIVE FILTERING

ระบบกรองข้อมูลอัจฉริยะ ช่วยให้คุณค้นหาชื่อเครือข่าย หรือกรองดูเฉพาะ THREAT ได้ในทันที

คู่มือการใช้งานเบื้องต้น

1. Radio Intelligence: ดูรายการ WiFi รอบตัวได้ที่หน้า Dashboard หลัก

2. การเฝ้าระวัง: หากพบสัญลักษณ์สีแดง (THREAT) ให้กดปุ่ม Dropdown แล้วเลือก Pin to Watchlist เพื่อแยกเป้าหมายออกมา

3. ความหมายของค่า RISK:
- 0-30%: เครือข่ายปกติ
- 31-70%: น่าสงสัย (SUSPECT) อาจเป็นอุปกรณ์แปลกปลอม
- 71-100%: อันตรายสูง (THREAT) มีพฤติกรรมคล้าย Evil Twin
